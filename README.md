# SnowWars

Сетевая игра в снежки на Godot 4.7. Игроки бегают по полю боя и кидают друг в друга
снежками; поддерживается выделенный сервер, клиент и локальный (офлайн) режим в одном
процессе.

## Открыть проект

Проект живёт в `src/GodotClientServer`. Откройте эту папку (файл `project.godot` в ней) в
Godot 4.7.

## Запуск

Стартовая сцена (`Launcher.tscn`) при запуске показывает экран выбора режима с тремя
кнопками — Server, Client, Local. Режим переключается через UI, а не аргументы командной
строки:

- **Server** — вводите порт (поле `PortLineEdit`, по умолчанию `4433`, если оставить пустым)
  и нажимаете «Server». Поднимается `ENetMultiplayerPeer` в режиме сервера, принимает до
  16 клиентов.
- **Client** — вводите адрес сервера (`HostLineEdit`) и порт (`ClientPortLineEdit`, по
  умолчанию `4433`) и нажимаете «Client». Подключается к запущенному серверу.
- **Local** — нажимаете «Local»: сервер и клиент поднимаются в одном процессе без реального
  сетевого пира, удобно для одиночной игры/быстрой проверки без второго инстанса.

Чтобы поиграть по сети локально на одной машине, запустите два инстанса игры (например,
через Godot editor + экспортированную сборку, либо два раза `godot` из командной строки):
один — «Server», второй — «Client» с адресом `127.0.0.1` и тем же портом.
