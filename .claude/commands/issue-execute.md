Выполни issue в текущем проекте, следуя процессу оркестрации из `CLAUDE.md`.

## 1. Определение issue

- Если передан аргумент `$1` — работай с issue `#$1` (`gh issue view $1`).
- Если аргумент не передан — найди следующую свободную issue:
  1. Получи открытые issue со статусом `Ready` на project board:
     `gh project item-list 1 --owner iRumba-org --format json`.
  2. Для каждой такой issue прочитай тело (`gh issue view <n>`) и найди пункт `Зависит от:`
     или похожую формулировку зависимости прозой — в этом репозитории зависимости между issue
     не выражены через нативные поля GitHub (`blocked-by`/`blocking` пустые), а описаны текстом
     со ссылкой на **название** другой issue.
  3. Issue считается свободной от зависимостей, если все issue, упомянутые в `Зависит от:`,
     уже имеют статус `Done` на board (или закрыты).
  4. Среди свободных issue возьми issue с наименьшим номером.
  5. Если ни одна `Ready`-issue не свободна от зависимостей — сообщи об этом пользователю и не
     начинай работу.

## 2. Выполнение

Дальше следуй правилам оркестрации из `CLAUDE.md`:

1. Переведи статус выбранной issue в `In Progress` на project board.
2. Создай ветку `тип/issue-<номер>-slug` от актуального `main` (тип — `feature`/`fix`/
   `refactor`/`docs`/`agent`, см. `CONTRIBUTING.md`).
3. Если правка тривиальная и однозначная — сразу поручи её **coder**. Иначе — собери
   недостающие факты через **researcher**, подгрузи скилл `planning`, составь план и получи
   подтверждение пользователя (Plan Mode).
4. После реализации — прогони проверку через **tester**; при найденных проблемах возвращайся
   к **coder**, пока не готово.
5. Закоммить, запушить ветку и открой Pull Request (`gh pr create`), сославшись на issue
   (`Refs #<номер>` в теле PR — это не закрывает issue автоматически).
6. Переведи статус issue в `Needs Review` на project board.

Не мержи PR и не закрывай issue в рамках этой команды — это отдельный шаг после ревью и мержа
(статус `Done` и закрытие issue выставляются только после мержа, согласно `CLAUDE.md`).
